# Spec Delta

## ADDED Requirements

### Requirement: Cohesive celestial composition
The portfolio SHALL present a cohesive designed space environment built from depth stars, orbital arcs, horizon forms, and layered parallax, without oversized celestial bodies or broad colored washes that compete with content.

#### Scenario: Visitor enters in dark mode
- **WHEN** a visitor opens the portfolio in dark mode on a capable desktop viewport
- **THEN** the composition presents orbital geometry, horizon forms, depth layers, and supporting stars with a clear foreground-to-background hierarchy

#### Scenario: Visitor enters in light mode
- **WHEN** a visitor opens the portfolio in light mode
- **THEN** the same celestial structure remains recognizable as a bright observatory-style composition with sufficient contrast for content

#### Scenario: Visitor scrolls through the page
- **WHEN** the visitor moves beyond the hero
- **THEN** orbital and horizon geometry continues across sections through localized, restrained accents while stars remain supporting texture and no large green wash dominates a section

#### Scenario: Enhanced motion is unavailable
- **WHEN** reduced motion, constrained capability, unavailable canvas, or disabled JavaScript prevents animation
- **THEN** the large celestial composition remains visible as an intentional static scene without obscuring content

### Requirement: Integrated Skills constellation
The Skills section SHALL present conventional skill categories as one visually integrated cosmic system with clear hierarchy, connective geometry, and dark-theme surfaces that belong to the surrounding environment.

#### Scenario: Recruiter scans Skills in dark mode
- **WHEN** the recruiter reaches Skills in dark mode
- **THEN** Frontend, Backend, AWS & DevOps, Data, Systems, and AI-Assisted Development appear as an integrated constellation rather than six visually detached generic cards

#### Scenario: Recruiter identifies strongest differentiators
- **WHEN** the recruiter scans the Skills composition
- **THEN** AWS & DevOps and AI-Assisted Development receive stronger visual emphasis while every remaining category and technology stays readable and comparable

#### Scenario: Decorative connections are unavailable
- **WHEN** inline geometry, motion, or JavaScript is unavailable
- **THEN** every skill category and technology remains visible in a logical document order without depending on constellation lines

#### Scenario: Skills reflow on mobile
- **WHEN** the Skills section is viewed at 320 CSS pixels wide
- **THEN** the composition becomes a readable single-column sequence with no clipped text, overlapping geometry, or horizontal page overflow

### Requirement: Prominent availability signal
The portfolio SHALL make Karthik's availability for full-stack software engineering roles in Canada prominent in the initial viewport and persistent navigation without relying on animation or color alone.

#### Scenario: Recruiter evaluates the initial viewport
- **WHEN** the portfolio first loads
- **THEN** the recruiter can immediately read that Karthik is open to full-stack software engineering roles in Canada and can activate a direct contact action

#### Scenario: Recruiter scrolls beyond the hero
- **WHEN** the recruiter views the persistent navigation on a desktop viewport
- **THEN** a compact textual open-to-work indicator remains available and links to the Contact section

#### Scenario: Visitor uses a screen reader or reduced motion
- **WHEN** animation is disabled or the availability indicator is announced without its visual styling
- **THEN** explicit text communicates availability and the contact destination without depending on a pulsing dot or green color
