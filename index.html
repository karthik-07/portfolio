ACTIVE BUILDPYTHON · ARCH LINUX · SYSTEMD · PACMAN

WhatBroke?

A local Linux forensics CLI that relates newly observed failures to the system changes that came before them.

WhatBroke? started after I got tired of comparing journalctl output and Pacman package history by hand on my own Arch Linux machine. The CLI compares systemd journal failures across boots, spots newly observed signatures, and shows the package changes that came before them.
